## V3-G3b plain 修复（R06）

按 `V3-G3B-PLAIN-FIX-INSTRUCTION.md` 执行。`py -3.11`（3.11.9），Windows 原生。

### 根因
`run_plain` 非 TTY 用 `has_data = bool(records)` 判成功 → API 返回 `[]`（source=api、
last_error=None、last_api_success_at 已更新，即**成功的空结果**）被判失败返 1。
附带：n/p 与 render_block 都不钳 offset（可翻到空页）；`detail N` 用绝对下标与当前页无关；
`print_block` 漏传 page_size；输出无净化；`StopIteration` 不算 EOF 且 close 不在 finally。

### 改法
- `result_for(snap) → (code, label)`：api 成功（含空）→0；cache 有记录→0（附 api error 注记）；
  有 last_error / source=memory / source=none →1。非 TTY 打印 `Result: <label>`。
- `_status_line` 复用 `views.freshness()`（MANUAL/STALE/CACHE/ERROR 可区分）。
- `clamp_offset(offset, total, page_size)` 钳到最后一页起始；三个 render 助手 + n/p/detail 全走它。
- `detail N` 改为相对当前页（`clamp_offset(offset)+N-1`），越界输出 `No such row (this page shows rows A-B)`。
- `_clean()`（先剥 ANSI CSI/OSC 及参数 → 再 `sanitize()`）+ `safe_out(out)`，所有输出统一过边界。
- EOF/KeyboardInterrupt/**StopIteration**/None 一律干净退出 0；TTY 循环体套 try/finally 保证 close。
